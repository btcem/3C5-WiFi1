# Glossaire

| Terme | Signification |
|---|---|
| **AP** | *Access Point* : point d'accès sans fil |
| **AP autonome** | Point d'accès qui se configure et fonctionne seul |
| **AP Fallback** | Fonction qui ramène un LAP à son WLC primaire dès qu'il redevient disponible |
| **CAPWAP** | *Control And Provisioning of Wireless Access Points* : protocole entre LAP et WLC (RFC 5415) |
| **Canal de contrôle** | Canal CAPWAP (UDP 5246) pour la gestion du LAP |
| **Canal de données** | Canal CAPWAP (UDP 5247) pour les trames des clients |
| **Discovery Request / Response** | Messages par lesquels le LAP cherche un WLC et celui-ci répond |
| **DTLS** | *Datagram Transport Layer Security* : chiffrement de type TLS pour UDP |
| **Echo Request / Response** | Messages de surveillance de la session de contrôle |
| **FlexConnect** | Mode où le LAP peut commuter lui-même le trafic des clients |
| **LAP** | *Lightweight Access Point* : point d'accès léger, géré par un WLC |
| **Local-MAC** | Répartition où le LAP assure l'acheminement des trames des clients |
| **Option 43** | Option DHCP spécifique au fournisseur, utilisée pour annoncer le WLC aux LAP |
| **PoE** | *Power over Ethernet* : alimentation par le câble réseau |
| **RRM** | *Radio Resource Management* : gestion automatique des canaux et des puissances |
| **Split-MAC** | Répartition où les trames des clients sont envoyées au WLC, qui les commute |
| **SSID** | Nom d'un réseau sans fil |
| **Trustpoint** | Point de confiance : certificat utilisé par le WLC |
| **WLC** | *Wireless LAN Controller* : contrôleur de réseau sans fil |
| **WMI** | *Wireless Management Interface* : interface IP de gestion du WLC |
